# Phase 2 路口初查

先以臺北市調查資料測試選址流程，研究地點仍可更換。市府歷史分析的表 1 列出忠孝東路沿線調查點，可先查核忠孝東路 × 敦化南路及忠孝東路 × 光復南路。歷史資料僅提供找路口的線索。

| 候選 | 既有線索 | 選址前應查核 |
|---|---|---|
| 忠孝東路 × 敦化南路 | 歷史調查路口 | 近期調查表頁碼、分向轉向量、機車流向、號誌週期與行人穿越 |
| 忠孝東路 × 光復南路 | 歷史調查路口 | 同上，另核對 OSM 車道、左轉與周邊路口排隊是否干擾 |

臺北市資料大平臺的 [112 年度一般路口調查](https://data.taipei/dataset/detail?id=78ad408c-5aeb-417d-9963-156c7c63d82b) 提供 PDF。[交通流量及特性調查資料](https://data.taipei/dataset/detail?id=68767aa4-6703-4760-8a0e-74c641d66b90) 可用於追查不同年度。

下一步逐表記錄路名、觀測日期、區間起訖、進口方向、轉向、車種及計量單位。PCU 與實際車輛數須分欄保存。逐時段列出缺值；只有尖峰調查時，額外產生的離峰需求應標為合成情境。若缺少行人數據，先完成車流 RQ1/RQ2。正式定案前需保存原表出處、OSM 範圍、資料授權與可重建的路網。
