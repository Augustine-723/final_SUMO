# 正式研究路口：臺中市興大路 × 學府路

地點為臺中市南區國立中興大學校門口，校址興大路 145 號。研究控制範圍為校門前的交叉口，包含校門方向車流與行人穿越。[中興大學交通資訊](https://www.nchu.edu.tw/about/mid/485)

## 路網定位

查核日期為 2026-11-23。OSM 中學府路與興大路共同連接的節點為 13021816568（WGS84 北緯 24.1241218、東經 120.6751494）。查核範圍為西 120.6729、南 24.1216、東 120.6775、北 24.1259。四段道路交會於同一節點，地圖來源為 © OpenStreetMap contributors（ODbL）。[節點](https://www.openstreetmap.org/node/13021816568) · [OSM XML](https://api.openstreetmap.org/api/0.6/map?bbox=120.6729,24.1216,120.6775,24.1259) · [授權](https://www.openstreetmap.org/copyright)

## 觀測資料狀態

| 項目 | 目前證據 | 接續工作 |
|---|---|---|
| 分向轉向車流 | 臺中交通局公開南區交通調查，已查的清單包含學府路其他路段。尚未取得本路口各進口的轉向原表。 | 優先找本路口同日、分時段、分車種的轉向資料。若需現場計數，建議每 15 分鐘依進口記錄左、直、右與校門進出。 |
| 車輛偵測器 | 臺中市有 VD 位置與動態資料。本站點涵蓋與可用日期仍待比對。 | 以座標及行駛方向配對；若只有進口總量，轉向比例仍需補測。 |
| 行人與號誌 | 已定位穿越設施；尚未取得本路口分向行人數、現行週期及各相秒數。 | 同步記錄各行穿線人數及號誌切換時刻，分開保存不同時段的時制。 |
